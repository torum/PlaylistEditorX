# PlaylistEditorX

A simple, cross-platform desktop playlist editor and converter. (work in progress)

This project is a direct port of [Image-viewer](https://github.com/torum/Image-viewer), which was originally developed in 2018 using [ObjectPascal/Lazarus](https://www.lazarus-ide.org/). This modern iteration has been rebuilt using C#/.NET and [Avalonia UI](https://github.com/AvaloniaUI/Avalonia).
